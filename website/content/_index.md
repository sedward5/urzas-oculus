Urza's Oculus is an experiment in making draft decisions easier to understand.

It brings together the history of a draft, card-level evidence, and explainable recommendations—so players can see not just what a pick suggests, but why.

**The goal is clarity, not autopilot.** Oculus is being built to help you learn the shape of a draft while keeping every decision yours.

## Built with care

Oculus is a native macOS project. Its long-term design favors local processing, reproducible data, and a shared recommendation engine that can be tested independently.
