# Security Policy

## Supported versions

Urza's Oculus is pre-release software. There are no stable releases with a formal support window. Security fixes will be prioritized for the current development branch.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues. Use GitHub's **Report a vulnerability** feature on the repository's Security tab to submit a private report. Include a description, impact, reproduction steps or proof of concept where safe, affected commit/branch, and suggested mitigation.

Please allow maintainers reasonable time to investigate and coordinate a fix before public disclosure.

## Privacy-sensitive reports

Do not attach real Arena recordings, screenshots containing personal information, local database files, credentials, or other private data to a report unless a secure transfer method has been arranged. Redact personal information from reproduction material.
